# 赛题要求与工程实现对照

## 第 1 项：安装摆杆位置监测装置

- K230 摄像头覆盖摆杆有效区域并识别钢球位置。
- `det_video_1_3.py` 将视觉坐标转换为相对摆杆中心 O 的毫米位置。
- K230 通过 UART1/UART2 链路发送 `BALL,...` 帧，主控端由 `k230_uart.c` 接收。
- OLED、K230 屏幕和串口协议共同提供运行状态观察手段。

## 第 2 项：小车循迹一圈并在 A 点停车

- `lap_test.c` 负责计时、里程、A 线识别、终点确认和停车状态机。
- `IR_Module.c` 负责 CD4051 八路红外采样、数字滤波和毫米误差计算。
- `control.c` 根据左右轮目标速度执行编码器速度 PI 控制。
- `MPU6050.c` 为弯道角速度跟踪和终点后备判断提供惯导数据。

## 第 3 项：静态钢球位置控制

- `ball_control.c` 控制摆杆角度，使钢球从 O 点移动到指定的 ±5 cm 位置。
- `stepper_emm.c` 封装 X42S 闭环步进电机通讯。
- K230 位置数据经过有效性、超时和范围检查后才进入钢球闭环。

## 第 4 项：A-B 直线循迹与钢球保持

- `empty.c` 的 M3 入口同时启动 `lap_test.c` 和 `ball_control.c`。
- 主控根据 K230 位置误差、速度阻尼和底盘加减速状态修正摆杆目标。
- 钢球数据超时、X42S 故障、编码器异常或 A-B 超时会触发安全停车。

## 测试边界

源码和历史构建记录只能说明工程具备相应的实现路径，不能代替实际赛道上的
整车验收。正式测试前应重新确认赛道长度、A/B 线位置、车轮参数、摆杆零位、
视觉标定和电池电压，并记录每次测试的时间与钢球最大偏差。
