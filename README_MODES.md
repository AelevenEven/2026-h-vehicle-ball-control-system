# 统一评审固件：三模式操作说明

本工程现在只需要烧录一次：

`keil/Objects/empty_LP_MSPM0G3507_nortos_keil.hex`

## 上电选择

1. 上电或复位后，OLED显示 `SELECT TEST MODE`。
2. 短按一次按键：切换到下一个模式。
3. 按住约0.8秒，看到 `RELEASE: ENTER` 后松开：确认当前模式。
4. OLED显示 `MODE LOCKED` 后进入对应任务。
5. 进入任务以后，按键恢复为正常的启动/停止键。
6. 如需更换模式，复位主控后重新选择；运行过程中不能误切换模式。

## 三个模式

### M1 TASK2 LAP

- 只运行第2项底盘循迹。
- 将前排8路循迹模块中心对准A点横线。
- 确认OLED进入TASK2 READY后，按键启动一圈循迹和A点停车。
- 第二个半圆弯道使用260 mm/s和1.50倍曲率前馈，完全丢线时以110 mm/s差速低速寻线；第一个弯道参数保持原值。

### M2 TASK3 BALL

- 运行第3项静态滚球。
- 小车保持静止，摆杆先放到物理平衡位置，钢球放在O点。
- 等待K230位置有效后按键启动，执行 `O -> +5 cm -> -5 cm并保持`。

### M3 TASK4 A-B

- 运行赛题第4项：A点启动，沿AB直线循迹并保持钢球在O点。
- 将小车循迹模块对准A线，钢球放在实际O点。
- 按键启动瞬间，程序自动把当前有效K230位置记录为本次O点零偏。
- 指定测试位置累计行驶1500 mm时判定通过B点，冻结并显示AB时间。
- 通过B点后继续约80 mm再停车，避免在B点前提前制动。
- 8秒内未通过B点则显示时间故障；滚球闭环在整个AB段持续保持相对位置0 mm。
- 为减小钢球惯性偏移，M3以120 mm/s脱离A线、250 mm/s²平滑加速至300 mm/s；按1.5 m赛道估算仍可在约5～6秒通过B点。
- 底盘加速、减速时，程序会根据左右轮目标速度变化提前补偿摆杆角度；K230视觉闭环继续修正剩余位置误差。
- 钢球偏差超过4 mm后底盘会连续降速，8 mm及以上限制为230 mm/s，在8秒时限内优先守住±1 cm；K230长时失联或X42S故障会联动停车。

## 安全约定

- 模式只允许在上电菜单中选择。
- 运行中再次按键执行停止，不会切换模式。
- M2/M3中K230位置持续失联时，X42S按原保护逻辑回到逻辑水平位置。
- M1保留原TASK2整圈A点停车保护；M3保留丢线、编码器和8秒AB超时保护。
