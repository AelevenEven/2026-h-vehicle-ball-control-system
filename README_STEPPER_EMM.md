# K230 + X42S Emm 滚球控制说明

## 1. 控制链路

当前工程的滚球执行机构已经由串口舵机替换为：

`K230钢球识别 -> UART1 -> MSPM0位置PD -> UART2 -> X42S(Emm) -> 升降连杆`

- K230继续发送校正后的有符号毫米位置；MSPM0现可直接解析`48.72`这类
  带两位小数的毫米字段，并四舍五入为整数毫米进入控制环。
- X42S 接管原舵机的 UART2 引脚。
- `Hardware/stepper_emm.c/.h` 实现 Emm 二进制协议、接收中断和回复校验。
- `Hardware/ball_control.c/.h` 实现钢球位置环、丢球回中和故障停机。
- 原 `Hardware/servo.c/.h` 已删除，Keil 工程引用已替换。
- 默认 `APP_MODE_H2_LAP` 下，滚球环和循迹状态机同时运行；可用
  `H2_BALL_BALANCE_ENABLE` 临时关闭滚球环做底盘诊断。

## 2. 接线

| 连接 | 用途 |
|---|---|
| MSPM0 PB17 / UART2 TX -> X42S `R/A/H` | 主控发送命令 |
| MSPM0 PB16 / UART2 RX <- X42S `T/B/L` | 接收电机回复 |
| MSPM0 GND -> X42S GND | 信号共地 |
| 10~29 V 独立电源 -> X42S `V+`、`GND` | 电机动力电源 |

不要用 MSPM0 的 3.3 V/5 V 引脚给电机供电。上述接法只适用于 TTL 串口版本；
RS485 版本必须增加收发器，不能直接接 PB17/PB16。

K230 保持原接线：

- K230 TX -> MSPM0 PB7 / UART1 RX
- MSPM0 PB6 / UART1 TX -> K230 Pin12 / UART2 RX（发送电机目标轴角度）
- 两块板共地，115200，8N1

## 3. X42S 菜单设置

在电机菜单中确认：

- 固件模式：`Emm`
- `P_Serial`：`UART_FUN`
- 波特率：`115200`
- 地址：`1`
- 校验：固定 `0x6B`
- 应答：建议 `Receive` 或 `Both`
- 细分：当前安全角度说明按 16 细分，即 3200 脉冲/圈计算

若改变地址、波特率、校验或细分，必须同步修改代码。

## 4. 上电和运行

结构图中没有原点开关或绝对角度传感器，因此采用人工水平置零：

1. 上电后先手动把摆杆调到水平。
2. 第一次按键进入 RUN 时，主控发送 `0A 6D`，把当前轴角设为软件零点；等待
   20 ms 后再发送使能，避免两帧粘包产生 `0xEE`。
3. 主控每 50 ms 根据 K230 的位置和球速更新绝对目标位置，并把目标脉冲换算
   成电机轴角度发送给 K230，用于多角度透视插值。
4. K230 连续丢球超过 350 ms，摆杆按限速逐步回到软件零点。
5. 按键停止或 TASK2 完成后发送立即停止，电机保持锁轴，不主动释放连杆。

默认平衡目标为 `0 mm`。当`empty.c`选择`APP_MODE_BALL_CONTROL`时，程序会自动
启用赛题第三项：按键后先把目标设为`+50 mm`，连续80 ms进入±8 mm范围后折返，
再把目标设为`-50 mm`；在-5 cm附近连续稳定300 ms后冻结完成时间并继续闭环保持。
总时间超过5000 ms时显示`TIMEOUT`并把摆杆目标缓慢恢复到软件零位。

OLED第三项界面显示：`P`为K230实测毫米位置，`T`为当前目标，`TM`为从按键启动
到完成稳定的毫秒数。完成时显示`DONE HOLD -5`。

其他模式下指定位置仍可调用：

```c
BallControl_SetTargetMm(50);
BallControl_SetTargetMm(-50);
BallControl_SetTargetMm(0);
```

允许设置范围是 `-120..+120 mm`。停止状态下重新手动调平后，可调用
`BallControl_RezeroAtCurrentPosition()` 更新软件零点。

## 5. 使用的 Emm 指令

- 当前角度清零：`01 0A 6D 6B`
- 使能：`01 F3 AB 01 00 6B`
- 停止：`01 FE 98 00 6B`
- 位置：`地址 FD 方向 速度高 速度低 加速度 脉冲数4字节 01 00 6B`

位置模式字节使用 `01`，表示相对于软件零点的绝对位置。这样连续控制不会像相对
命令那样累计漂移。未使用要求较新固件版本的快速位置模式。

电机回复格式为 `地址 功能码 状态 6B`。`02` 表示命令正确，`9F` 表示到位；
`12/22/E2/EE` 和接收缓冲区溢出会触发立即停止，并让整车进入安全停止。

## 6. 首次测试和调参

1. 先拆下连杆或让机构无负载，确认 PB17/PB16、共地和电机独立供电。
2. 手动调平，按键后检查电机只做小角度动作。
3. 轻移钢球：如果电机让球继续远离目标，只把
   `BALL_STEPPER_DIRECTION_SIGN` 从 `1` 改为 `-1`。
4. 装回连杆，先确认 `BALL_STEPPER_MAX_POSITION_PULSES=160` 不触碰机械限位。
5. 再调 `BALL_POSITION_KP_PULSE_PER_MM`；响应太慢可逐步增大，快速抖动则减小。
6. 球高速越过目标、往返振荡时，再逐步增大
   `BALL_VELOCITY_KD_PULSE_PER_MM_S`。

当前 160 脉冲在 16 细分下约为 18°，只是首次测试的保守限幅，最终应按实际曲柄
连杆的安全升降范围重新标定。

当前已经完成电机轴 `-18°～+18°` 的多角度视觉标定。MSPM0 每 50 ms 发送
`ANGLE,seq,angle_cdeg`，K230 按相邻角度表插值后再计算钢球位置。由于 X42S
内部闭环且本机构未安装独立角度传感器，当前角度采用“绝对位置目标脉冲换算值”；
运行中仍解析 X42S 的 `02/E2/EE` 命令应答，但不依赖不稳定的 `0x36` 查询。

## 7. 机械安全限制

现有结构图没有零位开关、上下限位或绝对位置传感器，所以程序无法在断电、丢步
或连杆打滑后自动恢复真实水平。正式比赛前建议增加原点开关和机械限位；在此之前，
每次重新上电都必须先人工调平，并先做无球低幅测试。
