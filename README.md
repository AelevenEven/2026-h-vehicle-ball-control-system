# 2026 全国大学生电子设计竞赛 H 题：车载平衡滚球运动控制系统

本仓库是依据《车载平衡滚球运动控制系统（H 题）》整理的独立工程，面向
MSPM0G3507 主控、K230 视觉模块、八路红外循迹模块和 X42S 闭环步进电机。
工程包含主控固件、钢球视觉程序、Keil 工程、参数说明和赛题对照资料；源码注释、
操作说明和项目介绍以中文为主。

> 说明：仓库中的控制参数来自当前参赛工程和实车调试记录。烧录前应按实际小车的
> 电机方向、编码器方向、摄像头位置、摆杆零位和赛道尺寸重新确认。编译通过不等于
> 已经完成整车测试。

## 项目目标

赛题要求小车沿黑色环形线路运行，同时通过摆杆机构使钢球稳定在指定位置附近。
本工程把底盘运动控制和钢球位置闭环组合为三个可在上电菜单中选择的模式：

| 模式 | 对应赛题 | 主要功能 |
| --- | --- | --- |
| M1 TASK2 LAP | 第 2 项 | 小车沿环形线路运行一圈并在 A 点附近停车 |
| M2 TASK3 BALL | 第 3 项 | 小车静止，钢球执行 O 点到 ±5 cm 的位置控制 |
| M3 TASK4 A-B | 第 4 项 | 小车沿 A-B 直线循迹，同时闭环保持钢球在 O 点附近 |

赛题关键指标包括：第 2 项总时间不超过 20 s、停车偏差不超过 2 cm；第 3 项
到达 ±5 cm 后稳定时间不超过 5 s 且误差绝对值不超过 1 cm；第 4 项 A-B
通过时间不超过 8 s 且钢球误差绝对值不超过 1 cm；整圈项目时间不超过 30 s。

## 主控使用方法

1. 用 Keil 打开 `keil/empty_LP_MSPM0G3507_nortos_keil.uvprojx`。
2. 编译并烧录主控程序。
3. 上电后 OLED 显示 `SELECT TEST MODE`。
4. 短按按键切换模式；按住约 0.8 s，看到 `RELEASE: ENTER` 后松开确认。
5. OLED 显示 `MODE LOCKED` 后，按键恢复为对应模式的启动/停止键。
6. 运行中再次按键只执行停止，不会切换模式；更换模式需要复位主控后重新选择。

详细操作和三个模式的测试前提见 [`README_MODES.md`](README_MODES.md)。

## K230 部署

将以下内容复制到 K230 的 `/data/` 或 `/sdcard/`：

- `视觉/钢球识别/main.py`
- `视觉/钢球识别/det_video_1_3.py`
- `视觉/钢球识别/mp_deployment_source/`

主控与 K230 的默认串口协议为：

```text
BALL,序号,状态,位置mm,X误差px,Y误差px,置信度千分数,中心X,中心Y\r\n
```

默认接线和摆杆位置标定方法见 [`视觉/钢球识别/README_协同控制.md`](视觉/钢球识别/README_协同控制.md)。
摄像头、摆杆或支架位置变化后，必须重新标定视觉坐标，不要直接沿用示例标定表。

## 编译与验证

Keil 工程文件：

```text
keil/empty_LP_MSPM0G3507_nortos_keil.uvprojx
```

可在 PowerShell 中使用 Keil 命令行构建：

```powershell
& 'D:\Keil5\UV4\UV4.exe' -r `
  'keil\empty_LP_MSPM0G3507_nortos_keil.uvprojx' -j0
```

生成的 `.hex`、`.axf`、`.map` 和中间目标文件属于构建产物，默认被 `.gitignore`
排除。建议先架空小车验证电机方向和编码器方向，再逐级提升循迹速度，最后进行
完整赛道测试。

推荐测试顺序：轮速与编码器 → 低速单排循迹 → A 线识别与停车 → K230 位置标定 →
静态 ±5 cm → A-B 联动 → 整圈测试。

## 参数入口

- `Hardware/task2_config.h`：TASK2 循迹、终点识别、停车和保护参数。
- `Hardware/ball_control.c`：钢球闭环增益、速度阻尼、X42S 行程限制和故障保护。
- `视觉/钢球识别/det_video_1_3.py`：摄像头分辨率、摆杆端点和多点位置标定。
- `empty.c`：上电模式选择及三个任务的组合入口。

涉及机械方向、传感器极性或零位的参数，必须先根据实车测量结果修改，并在架空
状态下确认安全行程。
