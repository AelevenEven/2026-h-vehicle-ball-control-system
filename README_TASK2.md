# 2026 电赛 H 题第 2 项底盘控制说明

## 1. 目标与当前默认模式

默认入口为 `empty.c` 中的 `APP_MODE_H2_LAP`。小车前排 8 路循迹模块中心
与 A 点横线重合后，OLED 显示 `START OK`，按键启动计时。小车先直行离开
横线，同时自动学习传感器中心到A线边缘的距离；进入闭环循迹并绕行一圈后，
重新识别 A 线前缘，再按本圈学习值回到相同的传感器中心基准点停车。

当前目标参数：

- 赛道估计长度：6140 mm；
- 正式最长时间：20000 ms；
- 正常直线速度：400 mm/s；
- 半径 500 mm 弯道速度：290 mm/s；
- 预计进入终点低速区的里程：6000 mm；
- 终点接近速度：70 mm/s；
- A线确认后以60 mm/s继续起步自动学习的距离，再清零目标和轮速PI；学习失败时
  使用9 mm备用值，并可通过微调参数按1 mm整定。

所有可调参数集中在 `Hardware/task2_config.h`。

## 4. 前排8路数据与控制

商家资料与当前实现一致：

- `AD2:AD1:AD0=000..111` 依次选择 X1..X8；
- 每次换路后等待 100 us；
- X1 在车左，X8 在车右；
- 传感器高电平表示检测到黑线。

前排物理位置默认使用：

```text
X1    X2    X3   X4   X5    X6    X7    X8
+35  +25   +15   +5   -5   -15   -25   -35 mm
```

正误差表示黑线在车辆左侧。误差按有效探头的毫米位置加权质心计算。全白时
不会把误差清零，而是保存最后有效方向，确认连续丢线后低速寻线。

滤波和转向：

- 每路状态使用最近3帧多数表决；
- 误差一阶低通系数 0.30；
- 微分基于滤波后误差，限幅 ±450 mm/s，再以 0.15 低通；
- 中心采用施密特迟滞：进入死区为 ±6 mm，离开死区为 ±10 mm；
- 比例增益从内区 `Kp=1.8` 连续增加至外区 `Kp=2.8`，`Kd=0.02`；
- 红外PD与曲率前馈合成后的转向最大 ±135 mm/s；
- 每个5 ms周期转向最大变化4 mm/s；
- 目标轮速限制为 0～450 mm/s，不允许普通循迹意外反转。

MPU6050不替代红外判断黑线位置。控制器按最终差速与150 mm暂定轮距计算
`yaw_rate_target = 2 * turn / wheel_track`，再用实测Z轴角速度修正差值。
因此直道目标角速度为0并抑制摆头，弯道则允许并跟踪正常角速度，不会把转弯
强拉回直行。MPU6050离线时自动退化为红外PD和曲率前馈。OLED显示
`TASK2 MPU`表示MPU6050在线，显示`TASK2 LINE`表示当前没有有效惯导反馈。

MPU6050上电后以200 Hz、陀螺仪±500 deg/s、加速度±2 g运行。初始化包含约
4.5秒静止零偏标定，上电期间必须保持车辆不动。当前安装约定为传感器+Y轴
指向车头、+X轴指向车右、+Z轴朝上；若左转时实测Z轴角速度为负，只翻转
`MPU6050_YAW_GYRO_SIGN`。WIT源码仍保留，但已从Keil构建和TASK2运行路径关闭。

里程模型按两段1500 mm直线和两个半径500 mm顺时针半圆生成弯道前馈，
直弯交界用150 mm线性过渡。前馈只提供基础右转量，红外闭环始终保留。

商家建议探头离地约 18 mm。模块左右必须水平；静止掩码稳定不代表车辆振动
时不会跨越数字阈值。

## 5. 状态机

```text
IDLE/自检
  -> READY/等待A线和按键
  -> STARTING/等速离开起始横线
  -> RUNNING/正常循迹
  -> APPROACH_STOP/终点前里程预减速
  -> FINAL_CREEP/A线确认和机械距离补偿
  -> BRAKING/目标归零并等待速度下降
  -> STOPPED/冻结时间
```

短时丢线进入 `LOST_LINE`，恢复20 ms后返回原状态；持续300 ms进入
`FAULT`。运行中再次按键、20秒超时、编码器疑似停转、左右轮严重不一致或
最终慢行超时也会进入 `FAULT` 并停止电机。

起点不会被误判为终点。终点识别必须同时满足：

- 已离开起点且里程超过400 mm；
- 行驶时间不少于8000 ms；
- 起步时保存实际A线的4～5路掩码，返回时允许左右偏移1个探头；
- 返回掩码至少3路识黑、与起点扩展掩码至少重合3路，并连续确认2帧，或者满足
  原有严格宽线连续确认；
- 里程处于5700～6700 mm正常终点窗口时，以A线掩码为主，不允许MPU6050漂移
  否决真实A线；
- 超出正常窗口时，必须至少达到5950 mm且回到起始航向±30°以内；
- MPU6050离线时，必须至少达到5950 mm才开放后备识别。

正常循迹线一般只有1～2路识黑，不能满足起点宽线匹配；最后弯道即使偶尔出现
较宽掩码，只要时间、最小里程和后备航向不合格仍会继续行驶。CSV中的
`marker_reject_reason`按位记录原因：1未解锁、2时间不足、4不在里程窗口、
8航向不符、16为MPU6050离线且里程不足。

## 6. 停车方式

现有 `motor.c` 没有给出可靠的H桥主动刹车真值表，因此没有编造主动刹车
电平。默认 `TASK2_REVERSE_BRAKE_ENABLE=0`，停车时左右目标速度和PWM归零，
并清除速度PI状态。

为了避免在高速下发现A线才开始减速，当前从里程约5700 mm开始进入
`APPROACH_STOP`：先降至220 mm/s，6000 mm后再降至80 mm/s。前排确认A线后
进入`FINAL_CREEP`，以40 mm/s完成最后的位置修正。补偿距离首先来自本圈起步时
自动测得的“A线中心到离开横线”距离，再根据到线时左右轮实际速度按
`d=v^2/(2a)`扣除预计制动距离，因此零速指令会在中心点之前发出，而不是到达
中心后才急停。停车后OLED的`GO`是确认A线后实际前进距离，`B`是本圈扣除的
制动距离，单位均为mm。

自动学习值只允许在4～40 mm范围内；异常时使用9 mm备用值，最终前进目标限制为
不超过30 mm。最终实测若仍有固定偏差，只修改
`TASK2_STOP_REFERENCE_TRIM_MM`：正值让车晚停，负值让车早停，建议每次调整
1～2 mm。若误差随到线速度明显变化，再调整`TASK2_STOP_BRAKE_DECEL_MM_S2`：
数值调小会更早制动，数值调大会更晚制动；不要改终点里程窗口补偿停车误差。

起步摆放必须始终以8路探头横排的几何中心为车辆基准，保持4～5路连续探头识黑、
X4和X5都在黑线上。若以后改用车身其他位置作为测量点，需要另行测量纵向偏移，
不能继续使用当前自动学习值。

## 7. 控制周期

| 周期 | 内容 |
|---|---|
| 1 ms | SysTick系统时间 |
| 5 ms | 前排完整扫描、误差滤波、迟滞PD、曲率前馈、MPU6050角速度跟踪、目标轮速 |
| 10 ms | TIMG0编码器速度、按键去抖、左右轮PI和PWM |
| 5～10 ms | TASK2状态和A线条件检查 |
| 50 ms | OLED更新 |

中断内不执行显示、printf或阻塞延时；动态内存未使用。

## 8. 调试输出

RAM黑匣子和停车后CSV回放当前均已关闭，`TASK2_BLACKBOX_ENABLE=0`，
`task2_log.c`不参与Keil构建。TASK2运行期间不执行周期性`printf`，释放约
16 KB RAM并避免串口格式化影响循迹周期。需要重新诊断时可再单独恢复该模块。

## 9. 调试模式

- 完整第2项：`empty.c` 中 `APP_RUN_MODE=APP_MODE_H2_LAP`，并保持
  `TASK2_FULL_TEST=1`。
- 左右轮速度测试：将 `APP_RUN_MODE` 改为 `APP_MODE_PID_TUNE`；目标值、
  实际值和PI输出会通过CH9102打印。
- 前排低速循迹：设置 `TASK2_FRONT_LINE_ONLY_TEST=1`，速度固定为
  150 mm/s。
- 停车线测试：已保留 `TASK2_STOP_LINE_TEST` 配置入口；正式启用前必须
  根据测试场地确定测试线前的最小时间和里程，避免绕过终点防误触条件。
- 双排测试：当前 `LINE_REAR_ENABLE=0`，因此自动退化为前排8路。
- 电机开环测试：未默认接入任务状态机。直接PWM测试具有机械风险，必须架空
  车辆并确认安全后再增加专用入口。

## 12. 建议调试顺序

1. 架空车辆做轮速测试，从100～150 mm/s开始，确认两路编码器正方向；
2. 落地给左右相同目标，测试2 m直行并确认左右实际速度稳定；
3. 前排探头离地调到约18 mm，移动黑线检查掩码由左向右移动；
4. 以150 mm/s做前排单排循迹，先观察目标速度，再观察实际速度；
5. 从200 mm/s逐级提升到400 mm/s，不要直接跳到最高速度；
6. 单独重复20次A线识别；
7. 实测驱动轮中心距并替换暂定的 `TASK2_WHEEL_TRACK_MM=150`；
8. 完整跑一圈，停车后记录OLED的 `GO`和`B`；若存在稳定同方向偏差，按1 mm步进调整
   `TASK2_STOP_REFERENCE_TRIM_MM`；
9. 重复20次停车，记录停车偏差；
10. 完整跑10圈，统计圈时、最大误差、平均误差和标准差；
11. 分别在满电和中等电量下复测，并连续运行30分钟检查热漂移。

内部验收目标：连续10圈无完全掉线，单圈不超过18 s，停车偏差不超过
±1 cm；正式底线为20 s和±2 cm。
